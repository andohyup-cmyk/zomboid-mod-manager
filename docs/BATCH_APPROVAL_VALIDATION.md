# 여러 모드 일괄 등록 검증 — UI·DB 무변경

기준: 2026-11-21, `feature/batch-approval-logic-tests-20261121`.

## 현재 구현 확인

- Steam URL 또는 Workshop ID를 1~20개 조회할 수 있다. 단일 ID에서 복수의 게임 Mod ID가 나올 수도 있으므로 Workshop ID와 Mod ID는 구별한다.
- 같은 Workshop의 서로 다른 출처(기존 GitHub 조사함 / Steam 정보 / 사용자별 영구 대기함)는 서로 다른 후보로 유지한다.
- 출처별 후보가 하나일 때만 일괄 **전체 선택** 대상으로 삼는다. 2개 이상이라면 사용자가 검토해 명시적으로 후보를 선택해야 한다.
- `저장 중`, `등록 완료`, `이미 등록됨` 상태는 선택 대상에서 제외한다. 실패 후 재시도 후보는 유지한다.
- 한 번의 승인에는 최대 20개를 포함한다. 기존 `ApprovalDialog`와 `BatchApprovalDialog`는 최종 승인 전 카탈로그 쓰기를 발생시키지 않는다.
- 실제 정식 카탈로그 저장은 Vercel Preview에서 차단된다. `POST /api/mods`가 정상 승인 호출을 처리하며 기존 Workshop의 중복은 409로 보고한다.
- 영구 대기함은 별도이며, GitHub 조사함을 눌러도 AI 신규 자동조사가 시작되는 것은 아니다.

## 이번 보강

`lib/batch-approval-selection.ts`에 선택·중복 상태 검증 로직을 분리하여
`components/ImportWorkbench.tsx`에서 호출한다. 화면 JSX, 버튼 위치, 라벨, 등록 API 및 DB 쓰기 정책은 변경하지 않았다.

`tests/batch-approval-selection.test.ts`는 다음을 검증한다:
- 실제 화면에 남아 있는 후보만 승인 대상에 포함
- 같은 ID의 갱신된 후보와 오래된 선택 객체를 구분
- 저장 중/완료/기존 등록 제외 및 실패 후 명시적 재시도
- 일괄 승인 최대 20개 제한과 21개째 보존
- 서로 다른 조사 출처가 충돌할 때 자동 선택 금지
- 명시적으로 선택한 여러 출처 중 하나는 승인 후보가 될 수 있음
- 원본 그룹과 선택 목록을 수정하지 않음

## 남은 실검증

- 실제 로그인 사용자의 다중 Workshop 입력과 Steam 외부 조회 실패·부분 성공의 모바일 화면 테스트
- 20개 일괄 승인/중복 409/일부 성공·일부 실패를 포함한 **격리된 시험 DB 쓰기 테스트**는 안전성 확인 및 별도 승인 이후
- 프로필에 실제 Mod ID를 붙이는 기능은 별도, 사용자 선택·순서 확정 전 자동 적용 금지
- 사용자 요구에 따라 홈·모드·서버 UI의 세부 디자인은 나중에 결정

**이 변경은 승인 없이 운영 배포·DB 권한·데이터·브랜치 병합을 수행하지 않는다.**
