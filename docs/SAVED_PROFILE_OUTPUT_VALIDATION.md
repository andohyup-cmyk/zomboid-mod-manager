# 7단계: 영구 저장 프로필 → 서버 설정 문자열 검증 연결

2026-11-21 기준, Project Zomboid Build 42.22 모드 관리 앱.

## 설계에서 확정된 경계

- 서버 프로필은 개별 게임 Mod ID와 Workshop 출처를 분리한다.
- 영구 저장된 비활성 선택은 기존 순서를 유지하지만 `Mods=`에는 포함하지 않는다.
- `Mods=`는 활성 게임 Mod ID를 **원래 선택 순서로**, 중복 없이 출력한다.
- `WorkshopItems=`는 대응하는 Workshop ID + 사용자가 명시한 다운로드 전용 Workshop ID를 중복 없이 출력한다.
- 선택이 없는 초안은 저장 가능하지만 설정 복사는 차단한다.
- 확정된 의존성 누락, 잘못된 ID, 명시적으로 확인된 선택 그룹 규칙 위반은 복사를 차단한다. 충돌·중복·로드 순서 위반은 확인을 요구하며, 미확인 정보는 별도 안내한다.
- **게임 Mod ID 접두사**는 자동 결정하지 않고 출력 시 사용자가 선택하도록 한다. 실제 B42.22 서버에 적용·서버 파일 덮어쓰기는 별도 범위.

## 구현

- `lib/saved-profile-output.ts`: `LoadedProfileSnapshot`을 기존 `buildProfileServerConfig`로 연결하는 순수 함수. DB·서버 파일 쓰기 없음.
- 저장된 각 선택의 `modIdUuid`, `workshopId`, `modId`가 **인증된 소유자 DB에서 읽은 신뢰 가능한 후보**와 정확히 일치하고 카탈로그에도 존재하는지 검사. 비활성 선택도 신원 검사 대상.
- 누락되거나 다른 Workshop으로 이동한 UUID, 중복 UUID, 서로 다른 UUID가 동일한 Workshop/Mod ID 쌍을 주장하는 경우 출력하지 않는다.
- 생성은 기존 검증 엔진 `lib/profile-server-output.ts` / `lib/server-config.ts`을 재사용한다. 기존 확인 근거가 있는 관계·배타 그룹을 별도로 전달받은 경우만 해당 규칙을 평가하며, 없는 근거를 새로 만들어내지 않는다.
- `GET /api/profile-snapshots?profileId=...&outputPrefix=none|backslash`: 본인 소유 최신 회차의 Mod ID를 복원한 뒤, **선택된 Mod ID 소속만** 사용한 제한적 기본 출력 미리보기를 옵션으로 반환. `outputPrefix`가 없으면 기존 조회 응답 유지.
- 미리보기 응답에는 `scope: "selected-mod-id-membership-only"`, `readyForCopy: false`를 명시한다. 이 조회에서는 DB의 확인된 의존성·카테고리·그룹·B42.22 호환성 근거를 아직 불러오지 않으므로 **복사 확정 검증이나 게임 적용 준비 완료를 뜻하지 않는다**. 앱 화면의 복사 기능은 연결하지 않는다.
- 테스트: `tests/saved-profile-output.test.ts`에서 선택·비활성 원위치·중복 제거·선택적 다운로드·빈 초안·잘못된 신원·검증된 의존성 차단·충돌 확인·그룹 규칙·접두사/입력 불변성 검증.

## 미완료

- 운영 DB 적용, 운영 배포, `main` 병합, 실제 서버 파일 수정, 홈·모드·서버 화면 변경 없음.
- 선택 그룹/카테고리의 영구 DB 저장 및 검증된 관계 원본을 API에 공급하는 작업은 별도 설계·승인 필요.
- 진짜 복사 준비 판정을 위해 전체 근거(특히 관계·배타·B42.22/멀티 확인 상태)를 읽어서 검증한 뒤, 사용자에게 확인창과 복사 행동을 제공해야 한다.
- 시험 DB에는 아직 영구 저장된 프로필이 없어 실제 로그인 브라우저의 저장→조회→출력 E2E는 미검증.
