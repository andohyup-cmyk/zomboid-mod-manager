# 서버 프로필 Mod ID의 활성 상태와 제거 정책

- 비활성화는 선택의 `enabled`를 `false`로 변경한다. 선택은 기존 위치와 대표 카테고리를 유지한다. 재활성화는 같은 위치에서 `enabled`만 `true`로 변경한다.
- 제거는 해당 프로필의 선택 목록에서만 수행한다. 카탈로그 항목과 개별 Mod ID 원본은 보존한다. 다시 추가할 때는 현재 카탈로그의 대표 카테고리와 카테고리 삽입 함수의 규칙을 적용한다. 비활성 선택도 삽입 위치를 계산할 때 목록에 포함한다.
- 상태 변경은 현재 순서를 그대로 사용한다. 제거 후에도 남은 선택의 상대적인 순서를 보존한다. 향후 서버 설정 출력에는 활성 선택만 현재 순서대로 전달한다. 설정 문자열 생성과 서버 파일 변경은 별도 범위다.

메모리에서 편집하는 선택은 Workshop ID와 실제 Mod ID의 쌍으로 식별한다. ID의 앞뒤 공백을 제거한 뒤 대소문자를 구분해 비교한다. 이는 로컬 선택 검증 커밋 `c3cdc28`과 카테고리 삽입 커밋 `10b3cc8`의 비교 방식과 일치한다. 저장 계층은 소유권이 확인된 카탈로그의 `mod_ids.id`와 프로필 ID로 선택을 식별한다. 순수 함수는 레코드에 포함된 UUID를 보존한다.

저장·RLS 초안 커밋 `83a35bb`에서 비활성 항목의 순서 유지와 선택 제거 범위는 위 정책으로 확정됐다. 제거 이력 보존과 저장 권한은 별도 결정 사항이다.
