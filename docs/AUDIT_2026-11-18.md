## 권장 검증 순서 (아직 수행 전)

1. **환경 보호**: Preview DB가 운영 DB와 같은지 확인. 분리 전 저장/삭제/승인 테스트 중지. 현재 운영 카탈로그 보존.
2. **비파괴 인증 검증**: 고정 Preview 링크로 로그인/로그아웃/운영 복귀 여부, 새로고침 API 권한 확인, Preview/Production 표기.
3. **읽기 시험**: 등록 대기 1건의 Workshop ID/Mod ID/출처/미확인 필드 점검. 승인 전 운영 카탈로그 변화 없음 확인.
4. **보안 통합 테스트**: 스테이징 DB에서 익명·허용/비허용 계정·다른 사용자 접근, RPC 단일 원자 저장·중복·실패 롤백. SQL/데이터 실제 적용 여부 확인.
5. **요구사항 격차 해결**: 숫자 ID/혼합 URL → 대기함 지속 → 선택·최종 확인 → 명시적 승인 저장. 유료 AI API 금지 확정 유지.
6. **데이터 모델 안정화**: Mod ID 선택 관계, 레코드 출처별 신뢰도, 향후 프로필별 출력 검증 규칙. 실제 서버 출력 자동 생성은 설계 후.
7. **안전망 추가**: 자동 테스트/잠금 파일/데이터 내보내기·복원/문서 최신화.
8. **운영 반영 여부 검토**: 시험 PR #2는 유지하고 검증 완료 후 사용자와 병합 여부 협의.
