# 모바일 모드 상세 카테고리 패널 — A안 구현 경계 (2026-11-22)

- **작업 브랜치:** `feature/mobile-mod-category-panel-20261122`, PR #36의 확정 HEAD 위의 별도 Draft PR.
- **UI:** 기존 `/mods/[id]` 상세 화면에 독립 카테고리 패널 1개 추가. 기존 홈/목록/프로필/게임 Mod ID 편집 화면은 변경하지 않음.
- **읽기:** 인증된 소유자만 통과하는 기존 GET API 2개를 `no-store`로 호출. 카테고리 UUID·이름·정렬·소속/대표 응답을 클라이언트에서도 검증하고, 누락/고아 소속/오류 시 수정 정보를 버리지 않고 안전하게 표시.
- **편집:** 다중 체크와 대표 하나 지정, 변경 취소/다시 조회/선택 미리보기 지원. 실제 저장은 기존 브랜치·시험 DB·쓰기 플래그 서버 게이트의 결과로만 활성화. 저장 시 다른 탭 사전 재조회→명시적 2차 확인→POST→재조회 확인을 순서대로 거침. **현재 이 브랜치에서는 서버 게이트가 false이므로 POST 버튼을 사용할 수 없음.**
- **0개 정책:** 미분류 기존 모드는 읽을 수 있지만 현 RPC는 0개로 저장하는 기능이 없음; 사용자 결정 전 자동 해제·삭제 금지.
- 카테고리 생성/이름 변경/삭제·대량 분류·카테고리별 목록 필터는 현재 범위에서 제외.
- 프로필의 실제 Mod ID, 활성/순서, 서버 설정 `Mods=`/`WorkshopItems=`, 태그·선택 그룹, 호환성 판정에 영향을 주지 않음.
- **미검증:** 사용자의 로그인 세션에서 실데이터 E2E, DB 쓰기 허용/fixture/정리, 운영 DB 마이그레이션 및 운영 적용. 보안 플래그·환경 변수·DB/RLS/OAuth 변경 없음. 개발 브랜치 테스트/Preview 검증은 PR에서 따로 보고.
