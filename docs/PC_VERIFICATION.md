# PC 복귀 후 검증 체크리스트 (준비 문서)

이 파일은 **PC에서 나중에 진행할 검증 절차**다. 작성 시점에 실제 PC 또는 게임 서버에서 실행했다는 뜻이 아니다. 모바일 우선 앱 개발을 먼저 진행하고, PC 사용이 가능해진 뒤 별도로 진행한다.

## 1. 개발 PC에서 앱 검증

1. PC의 GitHub 작업 폴더에서 브랜치 상태 확인: `git status --short`, `git branch --show-current`. 기존 미커밋 변경이 있으면 덮어쓰거나 브랜치를 임의 변경하지 않는다.
2. 승인된 작업 브랜치에서 `node --version`, `npm --version` 확인. 프로젝트 `package.json`의 Node 요구사항을 따른다.
3. PowerShell 프로젝트 루트에서 `./scripts/pc-verify.ps1` 실행. 스크립트는 `npm ci`, `npm run verify`, `npm run build`를 순서대로 호출하지만 배포하거나 DB를 변경하지 않는다.
4. Chromium이 준비되어 있다면 `./scripts/pc-verify.ps1 -Browser`로 브라우저 시험까지 진행한다. 설치가 필요하면 `npx playwright install chromium`을 별도로 실행한다. 브라우저 설치가 불가능하면 해당 단계만 보류한다.
5. Vercel Preview의 화면 테스트는 **운영 쓰기 테스트가 아니다.** 승인 전까지 영구 대기함/카탈로그 저장 보호를 우회하지 않는다.

## 2. Steam Workshop 실제 Mod ID 읽기 (읽기 전용)

1. Steam 라이브러리 폴더의 `steamapps/workshop/content/108600` 하위에서 숫자 Workshop 폴더가 있는지 확인한다. 다른 Steam 라이브러리 드라이브도 가능하다.
2. PowerShell에서 `./scripts/pc-audit-workshop.ps1 -WorkshopRoot "실제_워크숍_경로" -OutputPath "./zomboid-workshop-audit.json"` 실행.
3. 보고서의 `workshopId`, `modId`, `requires`, `relativePath`를 Steam 설명·게임 설정과 대조한다. 동일 Workshop의 복수 `mod.info`를 모두 기록한다.
4. 스크립트가 파일을 찾지 못하거나 기존 출력 파일이 있다면 **덮어쓰지 않고 중단**한다. 새로운 출력 파일명을 사용한다.
5. `mod.info`에 ID가 존재한다는 사실은 **B42.22 호환·멀티 안정성·서버 중간 추가 가능을 증명하지 않는다.** 해당 항목은 별개로 검증한다.

## 3. 게임·서버 연결 검증 (실제 PC 사용 가능 후)

- 테스트 서버 또는 복제된 안전한 구성을 사용한다. 게임 운영 서버나 저장 데이터를 임의 변경하지 않는다.
- 하나의 Workshop에서 여러 Mod ID 선택지를 제공하는 경우 각 기능·동시 활성화 허용 여부를 제작자 문서와 비교한다.
- 앱 출력 `WorkshopItems=`, `Mods=`가 실제 B42.22 서버 설정에서 허용되는 형태인지 확인한다. 특히 구분자, 역슬래시 접두사 옵션, 개별 Mod ID, 로드 순서, `Map=`은 **자동 추정 금지**.
- 서버에 적용하기 전 기존 `servertest.ini` 등 설정과 월드 저장 데이터에 대한 **별도 백업**이 준비되어 있는지 확인한다.
- 단독 접속 및 2인 접속에서 문 열기, 차량 탑승, 인벤토리 이동, 좀비 위치 동기화 항목을 구분해 기록한다. 모드 때문에 생긴 증상이라고 미리 단정하지 않는다.

## 4. 아직 별도 승인이 필요한 경계

- 시험 Supabase 영구 대기함/프로필/카탈로그 메타데이터 **마이그레이션 및 RLS 권한 적용**
- 운영 main 병합, Vercel 운영 배포, DB 권한/계정 설정 수정
- 게임 서버에 앱이 생성한 문자열을 실제 적용하거나 기존 파일 덮어쓰기
- OAuth 인증 문제의 실제 로그인 확인 및 안전한 RLS 실동작 검증 (도구로 가능한 읽기 점검은 별도 진행)

## 5. 로그·자료 취급

스크립트 보고서에는 상대적인 모드 경로와 Workshop/Mod ID만 포함한다. 토큰·OAuth 시크릿·개인 계정정보 또는 서버 비밀번호를 채팅/이슈에 복사하지 않는다. 모드의 로컬 설정 파일과 개인 사용자 저장 데이터도 기본 수집 대상이 아니다.

**실행 전까지 이 문서의 항목은 준비 완료이지 PC 실검증 완료가 아니다.**
