# 선택 그룹 기본 규칙 — 자유 선택

**사용자 확정: 2026-11-21, A안.**

- 선택 그룹은 카테고리·태그와 독립적이다.
- 기본 상태에서는 그룹 내 모드를 **0개부터 원하는 만큼** 선택할 수 있다.
- **필수** 규칙은 개별 그룹에서 명시적으로 최소 선택 수(예: 1)를 설정할 때만 적용한다.
- **배타** 규칙은 개별 그룹에서 명시적으로 최대 선택 수(예: 1)를 설정할 때만 적용한다.
- 그룹에 모드를 배치했다는 이유로 서버 프로필에서 자동 활성화/비활성화하거나 순서를 바꾸지 않는다.
- 최소/최대 선택 수, 그룹 간 중복 허용 정책 및 위반 시 복사 차단/경고 여부의 세부 UX는 이후 결정한다. 기본값을 임의로 필수/배타로 바꾸지 않는다.

## 준비된 코드
`lib/group-selection-rule.ts`의 `checkGroupSelection`은 기본 자유 선택과 명시적 최소·최대 선택 수의 유효성을 검증하는 **순수 함수**다. `tests/group-selection-rule.test.ts`에서 검증한다. 현재 서버 프로필 API, 실제 `Mods=` 생성 경로, DB, 화면에는 연결하지 않았다.

## DB 적용 보류
선택 그룹과 구성원·규칙을 저장할 테이블, RLS, 권한은 별도 검토와 사용자 승인이 필요하다. UI 디자인, 운영 배포, main 병합 및 데이터 변경은 하지 않는다.
