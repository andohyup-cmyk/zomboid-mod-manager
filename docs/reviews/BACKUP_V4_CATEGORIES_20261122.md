# JSON v4 백업: 다중 카테고리·대표 카테고리

기존 v3(10개 영역)를 임의 재해석하지 않고, 새 카테고리 3개 영역을 요구하는 v4(13개 영역)로 분리한다. v1·v2·v3은 열람 가능하지만 부분 백업으로 표시한다.

- 신규 영역: `categories`, `modCategories`, `modCategoryPrimary`. 소유자 RLS로 읽어 ID·이름·순서·다중 소속·대표 정확히 하나·참조 부모·64개 한도를 검사한다.
- 기존 모드·Mod ID·프로필·조사·승인/관계 참조 검증 보존. 원본 JSON 수정 없음.
- 읽기 실패·카테고리 참조 불일치는 503으로 안전하게 중단, 큐 읽기 실패는 기존처럼 부분 백업 가능. 테이블당 최대 10,000건·전체 8MB 제한 유지.
- **이번 범위에서 제외:** 운영 DB/운영 배포/main 병합, DB 마이그레이션·RLS 변경·쓰기·삭제·복구, 기존 모바일 UI 디자인 변경.
- **한계:** 순차 읽기는 트랜잭션 스냅샷이 아님. 전체 DB/PITR 백업과 실제 복구 검증, 실제 모바일 브라우저 내보내기 E2E는 별도 작업. 카테고리 스키마가 없는 환경에서 v4 내보내기가 503을 반환하는 것은 안전 실패다.
